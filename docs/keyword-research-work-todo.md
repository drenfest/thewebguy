# Keyword Research Work Todo

Last updated: 2026-06-28

This document turns the keyword research into an execution plan for `thewebguy.app`. It is intentionally task-oriented: each item should either improve an existing indexed page, create a supporting search asset, strengthen local/service topical coverage, or improve how the site routes visitors from search intent to a clear contact action.

## Current Baseline

- Site positioning: practical hourly website support at `$55/hr` for WordPress, website fixes, technical SEO implementation, landing pages, tracking, ecommerce, AI-built cleanup, agency overflow, and ongoing webmaster work.
- Indexed architecture: service pages, keyword service pages, skill pages, blog posts, location pages, sitemap, robots, schema helpers, canonical trailing slashes, FAQ schema, item lists, and AI discovery files are already in place.
- Strongest existing clusters:
  - WordPress support and WordPress issue repair.
  - Website fixes and broken-site troubleshooting.
  - Technical SEO implementation rather than audit-only consulting.
  - GA4, GTM, conversion tracking, and form tracking.
  - Agency overflow and white-label WordPress support.
  - Ecommerce support, WooCommerce checkout, Shopify Liquid, Merchant Center, and product data.
  - Local website support around Freeport, Rockford, and nearby regional cities.
  - AI-built website cleanup, vibe-coded site repair, and launch readiness.
- Main risk: several keyword service pages still rely on generated-style scaffolding. They target useful long-tail searches, but live snippets can expose repeated language and make the pages feel less specific than they should.

## Strategic SEO Lane

Do not compete primarily as a generic web design agency. The sharper lane is:

> Practical hourly website support for broken WordPress sites, SEO implementation, tracking fixes, agency overflow, AI-built cleanup, ecommerce cleanup, and local business website maintenance.

This lane matches the site's pricing, current content architecture, and the search intent where a buyer has a clear problem but may not know the exact service name.
