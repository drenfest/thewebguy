# `src/routes/about`

About page route at `/about/`.

## Files

- `+page.svelte`: explains the practical contractor positioning, experience areas, and technical skills without turning the site into a resume page.

## Common Patterns

- Uses `Seo`, `Hero`, `SectionHeading`, and shared card/check-list classes.
- Copy stays human and direct rather than corporate.
- Service and skill references point visitors toward actual work pages.

## How It Is Used

This page supports trust and context for visitors who want to understand the operator and work style before using the contact form.

## How To Extend

- Add specific proof points only when they support hiring decisions.
- Link new experience/service areas to existing service or skill pages.
- Keep personal-name mentions out if the current no-name site positioning remains.

## Suggested Improvements

- Add a compact work-history section if company names become part of public positioning.
- Add project examples once permission and screenshots are available.
