# Directory Submission Checklist

## Before Submitting

- Confirm the directory is relevant to web development, WordPress, SEO, ecommerce, local business, or agency services.
- Confirm whether the listing is free, paid, review-gated, or requires verification.
- Prepare the canonical URL: `https://thewebguy.app`.
- Prepare business name, description, categories, service area, logo, screenshots, and contact email.
- Check whether a profile already exists so duplicates are avoided.

## Submission Steps

1. Open `directory-submissions.csv`.
2. Pick the next `not_started` target with the highest priority.
3. Create or claim the profile using accurate business details.
4. Use one of the descriptions from `profile-copy.md`, then adjust it for the directory's audience.
5. Add the canonical website URL and any directly relevant service links the directory explicitly supports.
6. Submit verification or review requests if required.
7. Update the CSV status to `submitted`, `verified`, `needs_review`, `rejected`, or `not_applicable`.
8. Add notes with the login owner, verification date, profile URL, and any follow-up needed.

## After Approval

- Visit the live profile and confirm the link points to `https://thewebguy.app`.
- Check that the business name and categories are accurate.
- Add the final profile URL to the CSV notes.
- Add review-building tasks only where reviews are real, client-approved, and platform-compliant.

## Status Values

- `not_started`: no action taken yet.
- `submitted`: profile submitted but not yet approved or verified.
- `verified`: live listing confirmed.
- `needs_review`: blocked by missing details, verification, payment decision, or policy question.
- `rejected`: platform rejected the listing.
- `not_applicable`: directory was reviewed and intentionally skipped.
